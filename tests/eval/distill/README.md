# 老师擂台：哪位老师给的标签最可信

判定记录平台（`app/distill`）让任何模型当老师给判定打标。这里比较老师：同一批带真实答案的判定交给不同老师作答，看谁的概率区分得开、说得准。

## 第一轮：GLM-5.3 vs Jev（2026-09-25）

考场：真实多领域基准（`tests/eval/realbench`）按领域分层抽样 180 次判定（每领域 30，含 30 条静默查询），每次判定 36 条候选记忆的逐条判断 + 一道单选。Jev 的作答取评测时记下的原值，GLM-5.3（开思考）走 OpenAI 协议现场作答。

| 老师 | 逐条 AUC | Brier | ECE | 单选第一就对 | 静默判断 |
|---|---|---|---|---|---|
| Jev（jev-1.13.0） | 0.964 | 0.027 | 0.071 | 90.3% | 100% |
| GLM-5.3（开思考） | **0.985** | **0.014** | **0.034** | **91.4%** | 96.7% |

| 领域（AUC / 单选第一就对） | Jev | GLM-5.3 |
|---|---|---|
| legal | 0.897 / 70.0% | **0.989 / 80.0%** |
| biomed | 0.983 / 88.5% | **0.991 / 92.3%** |
| firefox | 0.987 / 95.8% | **0.9999 / 100%** |
| theorem | 0.985 / 94.7% | **0.993 / 100%** |
| security | **0.954 / 92.9%** | 0.972 / 71.4% |

GLM-5.3 整体是更好的老师（区分度与校准都更好，法律判例上差距最大），但在"CVE 对应哪个 CWE"的单选上明显不如 Jev。代价：每次判定约 1.24 万 token（含思考），中位 29.5 秒，只适合离线打标。

### 校准与合成（一半拟合、一半评估）

| | AUC | Brier | ECE | 单选第一就对 |
|---|---|---|---|---|
| Jev → 校准后 | 0.965 → 0.965 | 0.023 → 0.013 | 0.065 → **0.005** | 90.2% |
| GLM-5.3 → 校准后 | 0.990 → 0.990 | 0.011 → **0.007** | 0.031 → **0.004** | 94.1% |
| 合成（等权 / GLM 两倍权重） | 0.985 / 0.987 | 0.009 / 0.008 | 0.007 / 0.005 | 94.1% |

- 两位老师都偏向把"有用"说得太满，Platt 缩放后 ECE 降到 0.5% 以内。
- 目前最好的软标签是**校准后的 GLM-5.3 单独使用**；Jev 更弱，合成反而拖后腿。多老师合成要等接入更多强老师后，按擂台成绩定权重。

## 复现

```bash
# 老师配置:CE_TEACHERS_FILE 指向 JSON 列表(见 app/distill/teachers.example.json),密钥放 key_env 指定的环境变量
(real_env) .venv-eval/bin/python -m tests.eval.distill.arena --source eval:real_jev \
    --teachers real_jev-logged,glm-5.3 --per-domain 30 --name glm53_vs_jev
```

答案按（老师，题面哈希）缓存在 `data/cache/`，中断后重跑自动续上；报表写在 `reports/`。
